# Szampier Test

## How do I install these formulae?

`brew install szampier/test/<formula>`

Or `brew tap szampier/test` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "szampier/test"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
